# Vibe Coding 网页搭建向导 v0.1.1

首次公开测试版，建议在 GitHub 选择 **Pre-release**。

## 能力

- 自然语言访谈，帮助新手将建站想法转成需求与页面规格。
- 规划/开发双模式；需求与草图分别确认后才进入开发。
- 六份 Markdown 文档、版本检查、暂停与跨会话恢复。
- 标准 Skill 目录和 Codex skill-only 插件元数据，无专用 MCP、数据库或账号依赖。

## 本次修复

为 GitHub Actions 的 pip 缓存显式指定 requirements-dev.txt，解决 setup-python 在安装和测试前找不到默认依赖文件的问题。v0.1.1 包含该修复，原 v0.1.0 标签保持不变。

## 安装

下载本版本源码，将 skills/vibe-web-builder 整个目录复制到目标项目的 .agents/skills/ 下，按宿主要求重开 Codex 会话，再调用 `$vibe-web-builder`。具体搜索路径以所用 Codex 版本为准，详细步骤见仓库 README。附件可留空，GitHub 会提供源码 ZIP/TAR.GZ。
