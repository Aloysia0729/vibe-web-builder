# 验收门槛

## 自动检查

- SKILL.md metadata 合法、目录匹配、UI Prompt 可显式调用。
- manifest 满足已声明兼容 profile、资源路径存在，当前版本有 CHANGELOG。
- 六份模板完整且初始状态无确认，不含生成器遗留占位。
- 初始化不覆盖文件或经符号链接越界；错误路径返回非零。
- 两确认的版本错位、缺证据、规划模式实施、未知状态可被工具拒绝。
- 本地资源链接、基础敏感信息模式检查与工具测试通过。

## 行为验收

按 [15 类场景](behavior-scenarios.md) 逐步发送输入，检查实际答复和真实文件，不能只数关键词。每轮新问题不超过三，已明确信息不重问，规格足以指导实现，需求与草图确认分开，planning 停止，变更/恢复有效，敏感操作不越界。

独立代理或人工测试须记录输入、每轮响应、文件变更、判定和限制。一次场景成功不能代表所有模型/宿主均通过。自动工具的门槛检查也不能证明模型永远遵守门槛。

## 发布判定

只有自动检查、关键行为和实际宿主安装发现都完成且无阻塞失败，才称为可正式发布。GitHub Actions、远端安装和公开 Release 状态分别记录。当前本地证据见 [验证记录](validation-report.md)；未运行项保持未运行，不用“全部通过”概括。
