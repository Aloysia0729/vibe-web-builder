## 视觉规范

以下为草图 v1 的视觉方案，已于第 3 轮获得用户独立确认：

- 配色：深灰背景 #111111，主体文字 #EFEDE9，辅助文字 #BDBDBD，分隔线 #383838。让照片成为主要视觉内容。
- 字体：清晰的无衬线中文字体；标题约 40–48px，手机 28–34px，正文 18px 起，辅助说明至少 16px。数值为规划建议，不是网页排版实测。
- 留白：桌面内容最大宽度约 1200px，左右边距 40px 起；手机左右 24px。模块间约 48–80px，图片区间距约 24–32px。
- 图片：首页一幅大主图，下方两幅精选图作结构示例；作品页按实际照片数量延续。保持原图比例，不在未见素材时决定裁切。文字线框只示意位置，不代表具体作品内容。
- 组件：简单文字导航、一个“查看全部作品”链接、纯文本邮箱。无装饰图标或动画需求。
- 可访问性规划：正文与背景保持清晰对比；当前页同时有下划线和语义标记；键盘焦点可见；图片提供描述性替代文本；主要导航触控区域至少 44px。当前均为规格，未作浏览器验收。

## 布局、导航与模块

全局：页顶品牌名左、导航右；品牌名可返回 P01。手机导航移到品牌名下一行，三个入口始终显示。全站沿用背景、文字、内容边距和页脚。

P01：标题和介绍在照片上方，避免文字遮住作品；主图后放查看全部作品链接，再放精选图。手机全部纵排，精选由双列变单列。精选数量可随素材调整，不新增功能。

P02：标题后为宽幅双列照片列表，说明位于对应照片下方；手机单列。保留原图比例，纵向滚动，无分页、分类或点击放大。

P03：左对齐的联系标题、简短提示和醒目邮箱，留出较多空白。手机同样纵排，长邮箱可换行但不截断。没有表单或其他联系方式。

建议桌面双列阈值约 900px；窄于此宽度改为单列，导航按空间换行。这些是原始布局规格；本次真实浏览器检查及宽度见 progress.md。404 等异常提示沿用全局导航与视觉规范，未另画草图。
