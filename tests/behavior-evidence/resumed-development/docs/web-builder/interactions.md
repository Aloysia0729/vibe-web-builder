## 表单与数据

联系表单与登录不适用：用户明确不需要。按已确认总结中的静态内容默认规划，无用户提交数据、后台或数据库。邮箱仅显示文本 contact@example.invalid，不设 mailto 链接。不涉及第三方服务或服务端数据保存。

## 关键用户流程

主流程：P01 首页 → I02 查看全部作品 → P02 通过 I03 浏览照片 → I01 联系导航 → P03 通过 I04 查看并选择邮箱文本。关联 T03 页面与草图规格。

直接入口：潜在客户直接打开 /works 或 /contact → 通过 I01 回首页或切换页面，无登录或授权前置条件。键盘焦点顺序遵循页面阅读顺序：品牌与导航 → 首页作品入口（如适用）。纯展示图片和邮箱文本不伪装成按钮。
