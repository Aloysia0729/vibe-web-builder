## 导航与页面关系

本页面规格依据已确认需求 v1 细化，并随草图 v1 在第 3 轮获得用户独立确认。本次恢复已按这些路径生成本地静态页面，验证见 progress.md。

| 导航元素 | 目标 | 所在页面 |
|---|---|---|
| 姓名或品牌 / 首页 | P01 / | 全部三页 |
| 作品 | P02 /works | 全部三页 |
| 联系 | P03 /contact | 全部三页 |
| 查看全部作品 | P02 /works | P01 |

当前页面导航用下划线与当前页语义标记，不仅依靠颜色。所有页面均可直接访问并通过全局导航返回首页；不设置作品详情页或额外导航层级。

## 移动端与异常入口

桌面：品牌名在左，三页导航在右。手机：品牌名与导航分两行，三个导航项直接显示，无需折叠菜单。作品桌面双列、手机单列；长内容继续纵向滚动，邮箱较长时允许换行且不截断。

不存在路径的规划建议：显示“页面不存在”并提供“返回首页”；沿用三页导航，不增加业务页面。无登录，未授权入口不适用。本次实现带全局导航的 404、本地静态路由和手机样式；实测与限制见 progress.md。
