| ID | 页面 | 范围 |

| P01 | 登录 | 邮箱密码登录；同页切换自助注册、找回密码 |

- Next.js + TypeScript、Supabase Auth 与 PostgreSQL 的技术方案沿用；数据库权限隔离本人数据。
