## 表单与数据

- 邮箱使用带 label 的 email 输入；密码使用 password 输入，不写入日志、文档或笔记表。
- 笔记标题为单行文本，正文为多行纯文本，均以文本渲染，不能当 HTML 执行。
- 数据字段：id、owner_id、title、body、created_at、updated_at；目前为设计，无数据表或迁移。
- 新增时 owner_id 来自已认证用户。数据库对 select、insert、update 都检查用户与 owner_id 一致；update 不能借修改 owner_id 转移数据。取消删除功能后不提供删除接口，数据库不向普通应用用户开放笔记删除策略，直接发起删除请求也应被拒绝。
- 详情不存在与越权统一反馈，不泄露他人内容。客户端过滤和隐藏按钮不能代替服务器权限。
- 保存明确为手动触发；以服务器成功响应为准。无离线同步承诺，不把未保存草稿称为跨设备已保存。
- 同一笔记多设备同时写入不属于实时协作；实现时须明确覆盖语义并避免展示虚假的保存成功。

## 可访问性与焦点

输入框均有可见标签，错误文本关联对应输入；反馈区可被辅助技术读取。键盘顺序按视觉从上到下，焦点轮廓可见；确认框可用 Escape 取消、关闭后回触发按钮；按钮不只靠颜色表达含义，手机触控目标约 44px。
