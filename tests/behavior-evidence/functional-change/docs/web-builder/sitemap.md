| 页面 ID | 名称/用途 | 访问者 | 路径/入口 | 核心模块 | 可执行操作 | 跳转目标 | 范围 |
|---|---|---|---|---|---|---|---|
| P01 | 登录 | 未登录成员 | /login；未登录访问笔记时进入 | 产品名、邮箱密码表单、注册/找回密码切换、错误反馈 | 登录、切换注册、发送重置邮件、重置密码 | 成功进入 P02 或合法的本人笔记返回地址 | MVP |

| P03 | 创建或编辑本人笔记 | 已登录成员；已有笔记须属本人 | /notes/new 或 /notes/[id]，从 P02 进入 | 返回列表、页面标题、保存与状态、笔记标题、正文 | 编辑、保存、返回、退出 | 保存新笔记后替换为该笔记地址；返回后进入 P02 | MVP |

/notes/new 与 /notes/[id] 为同一编辑页面的两种状态，不新增主页面。注册、找回密码、重置密码同样是 P01 的表单状态。

## 导航与页面关系

| 起点 | 操作 | 结果 |
|---|---|---|
| P01 | 登录成功 | P02；内部返回地址通过校验后可回 P03 |
| P02 | 新建笔记 | P03 新建状态，未保存前不产生服务器记录 |
| P02 | 打开列表项 | P03 对应本人笔记 |
| P03 | 首次保存成功 | 留在编辑页，地址替换为新笔记 ID |
| P03 | 返回列表 | 有未保存修改先处理保存/放弃/继续编辑 |
| P02/P03 | 退出成功 | P01；P03 有未保存内容先提示 |

## 移动端与异常入口

桌面列表与编辑内容居中，保持单列；手机减少两侧留白，按钮与状态换行，编辑正文占据主要空间。返回列表始终可见，不依赖浏览器后退。

未登录访问 P02/P03 转 P01。不存在与不属于本人的笔记统一展示“无法打开这条笔记”，提供返回列表入口，不泄露标题或所有者。未知路径用轻量未找到状态并提供回列表或登录的入口，不增加业务主页面。列表请求失败提供重试；空列表提供新建按钮。
