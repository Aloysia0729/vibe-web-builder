## 视觉规范提案

- 浅灰白背景 #F7F8FA，白色内容区 #FFFFFF，深灰正文 #1F2937，次要文字 #64748B，浅灰分隔线 #E2E8F0。
- 主按钮使用蓝色 #2563EB 与白字；错误使用红色文字并配明确文字，颜色不单独传达状态。
- 系统无衬线字体；正文建议 16px、约 1.6 行高，标题 24px。间距以 8px 递增，控件约 44px 高，轻边框、少量圆角，避免装饰大图。
- 产品暂用“团队笔记”文字标识，不引入未获授权图片；返回使用箭头加文字。
- 登录卡片桌面最大宽约 420px；列表与编辑主体最大宽约 960px。移动端 16px 两侧留白，按钮不溢出。
- 以上视觉与具体位置均为 Proposed，需求 v2 确认后再等待草图 v2 独立确认；未做浏览器对比度或响应式实测。

## 核心页面草图：桌面

### P01 登录（I01、I05）

```text
┌─────────────────────────────────────────────────┐
│ 团队笔记                                         │
│                                                 │
│             登录，继续记录你的笔记                │
│        ┌───────────────────────────────┐        │
│        │ 邮箱                          │        │
│        │ [输入邮箱                   ] │        │
│        │ 密码                          │        │
│        │ [输入密码                   ] │        │
│        │ [          登录 I01         ] │        │
│        │ 注册 I05          找回密码 I05│        │
│        │ 表单错误 / 操作反馈区域       │        │
│        └───────────────────────────────┘        │
```

注册模式保留同一张卡片，补确认密码，主按钮改“注册”；找回密码模式只保留邮箱和“发送重置邮件”；重置回跳仍在 P01 的新密码状态。各状态提供回登录入口，不增加主页面。

### P02 我的笔记（I02、I03、I06）

```text
┌─────────────────────────────────────────────────┐
│ 团队笔记                         当前账号  退出   │
├─────────────────────────────────────────────────┤
│ 我的笔记                         [+ 新建笔记]    │
│                                                 │
│ ┌─────────────────────────────────────────────┐ │
│ │ 项目想法                       10 分钟前     │ │
│ │ 今天记录的内容摘要……                        │ │
│ ├─────────────────────────────────────────────┤ │
│ │ 个人待办                       昨天         │ │
│ │ 下一步准备……                                │ │

│ 点击整行打开；按最近更新时间排序                 │
└─────────────────────────────────────────────────┘
```

这里的标题和摘要是布局示意文字。空列表在内容区显示“还没有笔记”和新建入口；加载显示占位；错误展示重试按钮。只列出当前成员的笔记。

```text
│ │ 在这里写下你的笔记……                        │ │
│ │                                             │ │
```

新建状态标题为“新建笔记”；首次成功保存后进入该笔记的编辑状态。加载与无权/不存在状态保留返回列表入口；无权与不存在使用相同通用文案。

## 手机排列

三页保持单列，不新增侧栏或菜单。

```text
P01 登录             P02 我的笔记          P03 编辑
┌────────────────┐  ┌──────────────────┐ ┌──────────────────┐
│ 团队笔记        │  │ 团队笔记    退出 │ │ 团队笔记    退出 │
│ 登录            │  │ 当前账号         │ │ 当前账号         │
│ 邮箱 [        ] │  │ 我的笔记         │ │ ← 返回列表       │
│ 密码 [        ] │  │ [+ 新建笔记]     │ │ 编辑笔记  [保存] │
│ [     登录    ] │  │ 标题 / 时间      │ │ 未保存           │
│ 注册 / 找回密码 │  │ 摘要……           │ │ 标题 [         ] │
│ 操作反馈        │  │ 标题 / 时间      │ │ 正文 [         ] │
└────────────────┘  │ 摘要……           │ │ [              ] │
                    └──────────────────┘ │                  │
                                         └──────────────────┘
```

手机登录卡片占可用宽度；长账号换行。列表标题与新建按钮上下排列，行项允许摘要换行。编辑页保存按钮仍位于内容顶部，状态在下一行。未保存离开确认框在手机上按可用宽度展示并可键盘访问。

## 页面关系与关键反馈

P01 登录 → P02 列表 → P03 新建或编辑 → 保存后留 P03，返回后回 P02。保存中防重复提交；失败保留输入；有未保存修改时返回或退出先确认。编辑页不再展示删除按钮或删除确认框。
